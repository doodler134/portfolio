# Portfolio — cloud + mobile

Статический сайт-портфолио для GitHub Pages. Никакого npm не требуется.

## Что есть

- выраженный 3D tilt без свечения курсора;
- fullscreen просмотр;
- редактор с drag & drop;
- PNG/JPG/WEBP/GIF;
- облачное хранение изображений и настроек через Supabase;
- локальный кэш через IndexedDB/localStorage;
- мобильный редактор в виде нижней панели;
- стилизованные select и ползунки;
- настройки колонок, отступов, 3D, масштаба, подъёма, скругления, тени;
- настройки фона: размер, позиция, прозрачность, размытие;
- затемнение страницы убрано полностью;
- демо-шаблоны не создаются — новый проект пустой;
- GitHub Pages ready.

## Локальный запуск

Открой `index.html` напрямую или запусти: 

```bash
python -m http.server 8000
```

Открой `http://localhost:8000`.

## Supabase

1. В Supabase выполни `supabase.sql`.
2. Создай пользователя редактора в Authentication → Users.
3. В `config.js` укажи Project URL и Publishable key.
4. Не используй `service_role`/secret key в браузере.
5. В Storage должен существовать публичный bucket `portfolio-media` (SQL создаёт его автоматически).

## GitHub Pages

Загрузи содержимое этой папки в репозиторий. GitHub Pages будет отдавать `index.html` как обычный статический сайт.

## Как обновлять сайт

Если меняется только контент — ничего на GitHub обновлять не нужно: редактируй через Edit, данные уйдут в Supabase.

Если меняется код/дизайн: замени `index.html` (и при необходимости `config.js`) в репозитории, сделай commit/push. GitHub Pages сам обновит сайт через некоторое время.

Важно: `config.js` содержит только публичный publishable key. Secret/service_role key туда не добавляй.


### Важно про обновление

- Если меняешь постеры, фон, текст или настройки через **Edit**, GitHub трогать не нужно — это контент и он сохраняется в Supabase.
- Если меняешь `index.html`, `config.js` или другие файлы проекта, загрузи новые файлы в тот же GitHub-репозиторий и сделай **Commit changes**. GitHub Pages автоматически опубликует новую версию.
- Не удаляй `config.js`: в нём лежит подключение к Supabase.
